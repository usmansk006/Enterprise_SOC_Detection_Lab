# Contributing

Contributions are welcome when they improve the quality, clarity, and operational correctness of the detection engineering lab.

## How to contribute

- Keep content relevant to the HTA detection engineering lab and SIEM-independent detection work.
- Prefer realistic, evidence-based documentation over speculation.
- Cite telemetry assumptions and constraints where Windows event data is incomplete or environment-dependent.
- Use safe synthetic test fixtures and clearly label them as synthetic.
- Follow the existing repository structure and naming conventions.

## Contribution expectations

- Prefer clear Markdown documentation and maintainable Python scripts.
- Keep content consistent with Windows telemetry terminology and Sigma conventions.
- Document any assumptions or limitations in the relevant README or report.
- For detection rules, include telemetry requirements and validation status.
- For scripts, include usage examples and expected outputs.

## Pull requests

Open a pull request with a clear summary of:

- the change made,
- the detection or documentation area affected,
- validation performed,
- and any known limitations.

## Prohibited content

Do not commit:

- credentials or secrets,
- private telemetry,
- personal information,
- unauthorized screenshots from production environments,
- or malicious payloads.

This repository is meant to be a defensive engineering and documentation project for authorized lab use only.
