# Detection Rules

This directory stores a local-first collection of Sigma-style rules and supporting documentation.

## Contents

- `sigma/` for Sigma YAML content
- `windows-event-queries/` for query examples
- `powershell/` for PowerShell helper logic
- `correlation-logic/` for workflow and event linking notes

## Important note

Sigma rules are not execution engines. They require a compatible rule processor or conversion layer to be used operationally.
