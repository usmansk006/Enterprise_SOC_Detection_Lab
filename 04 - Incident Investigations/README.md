# 04 — Incident Investigations

This section contains documented security incidents investigated through the Wazuh SOC homelab.

## Investigation Lifecycle

1. Detection
2. Triage
3. Investigation
4. Evidence Collection
5. Impact Assessment
6. Containment
7. Remediation
8. Lessons Learned

## Incident Documentation

Each incident will include:

- Incident ID
- Detection timestamp
- Affected endpoint
- Detection source
- Severity
- Indicators of compromise
- Investigation timeline
- Evidence
- Root-cause analysis
- Response actions
- Recommendations
- Lessons learned
