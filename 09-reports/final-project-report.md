# Final Project Report Template

## Overview

This report documents the design, implementation, validation posture, and limitations of the HTA Sentinel detection engineering lab.

## Scope

- Windows telmetry collection and Sysmon setup
- HTA-related detection hypotheses
- Python tooling for parsing and correlation
- validation and test framework
- threat hunting and investigation workflow

## Status

The project is intentionally presented as a documented, maintainable, and partially validated lab architecture. Live Windows validation has not been completed in this environment.

## Gaps

- live testing not run
- production telemetry not collected here
- certain detections require more complete Windows logging
