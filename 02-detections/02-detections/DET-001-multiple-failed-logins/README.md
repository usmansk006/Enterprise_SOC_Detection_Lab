# DET-001 — Failed Windows Authentication

## Overview

This detection identifies failed Windows authentication attempts generated on the monitored Windows endpoint.

The detection uses Windows Security Event ID `4625`, which is generated when a logon attempt fails.

Wazuh collects the Windows Security event from the monitored endpoint, analyzes the telemetry using its detection rules, and generates a security alert for investigation.

Failed authentication activity can occur for legitimate reasons. However, repeated or unusual failures may indicate password guessing, invalid credentials, unauthorized access attempts, or other suspicious authentication activity.

## Threat Scenario

Failed authentication events may occur when a user or process attempts to authenticate using invalid credentials.

Potential causes include:

* Incorrect passwords
* Invalid usernames
* Expired credentials
* Misconfigured services
* Applications using outdated credentials
* Unauthorized authentication attempts

Repeated failures involving the same account, multiple accounts, or unusual timing may require additional investigation.

---

## Detection Logic

The detection is based on Windows Security Event ID `4625`.

Detection flow:

```text
Windows Authentication Failure
        ↓
Windows Security Event ID 4625
        ↓
Wazuh Agent
        ↓
Wazuh Manager
        ↓
Wazuh Rule 60122
        ↓
Security Alert
        ↓
SOC Analyst Investigation
```

A single authentication failure does not automatically indicate malicious activity.

The surrounding authentication context must be investigated.

## Investigation Considerations

When investigating failed authentication activity, an analyst should review:

* Target username
* Source address
* Logon type
* Authentication package
* Logon process
* Number of failures
* Frequency of failures
* Other targeted usernames
* Successful logons following failures
* Related process and network activity

A single failed authentication event should not automatically be classified as a brute-force attack.

---

## False Positives

Potential legitimate causes include:

* User entering an incorrect password
* Expired credentials
* Incorrect service credentials
* Applications using outdated credentials
* Scheduled tasks using invalid credentials
* Local authentication failures

Repeated or unusual authentication failures require additional investigation.

---

## Detection Limitations

This detection identifies individual Windows authentication failures.

Limitations include:

* A single Event ID 4625 does not confirm malicious activity.
* The detection does not independently prove brute-force activity.
* Additional event correlation is required to identify repeated failures.
* Source addresses may require contextual analysis.
* Local authentication activity may generate legitimate failures.

The observed source address in this lab was `127.0.0.1`, which indicates local loopback activity.

---

## Tuning Considerations

Potential improvements include:

* Correlating multiple Event ID 4625 events.
* Monitoring failures within a defined time window.
* Identifying multiple targeted usernames.
* Identifying repeated failures from the same source.
* Correlating Event ID 4625 with successful Event ID 4624 logons.
* Investigating unusual logon types.

Any tuning should be based on observed legitimate authentication behavior.
