# INV-001: Suspicious Encoded PowerShell Execution

## Investigation Overview

This investigation examines a Wazuh alert generated for PowerShell execution using the `-EncodedCommand` parameter on a Windows endpoint.

The investigation was conducted using endpoint telemetry collected through Sysmon and monitored through Wazuh.

The objective was to determine:

- What triggered the alert
- Which process executed the encoded PowerShell command
- What the encoded command contained
- How long the process executed
- Whether related or repeated activity was present
- Whether the activity represented malicious behavior

## Investigation Summary

Wazuh detected PowerShell execution using an encoded command on the monitored Windows endpoint.

Sysmon process creation telemetry identified the PowerShell process and captured the associated command line. The encoded command was decoded and analyzed without executing the decoded content.

The decoded command was determined to be:

`Write-Output "detcon PowerShell Test"`

The PowerShell process terminated shortly after execution. Investigation scoping identified no additional encoded PowerShell executions matching the detection criteria within the selected investigation timeframe.

The activity was determined to be authorized laboratory testing.

## Investigation Verdict

**Benign True Positive**

The detection correctly identified PowerShell execution using the `-EncodedCommand` parameter.

The decoded command was harmless and the activity was generated as part of authorized testing within an isolated laboratory environment.
