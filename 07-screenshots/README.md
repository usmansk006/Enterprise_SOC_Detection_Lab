# 07 — Evidence Screenshots

This directory contains curated visual evidence supporting the SOC lab, security detections, threat-hunting activities, and incident investigations.

## Evidence Categories

### Lab
Screenshots demonstrating the Wazuh infrastructure and endpoint configuration.

### Dashboard
Screenshots demonstrating Wazuh monitoring, agent status, and security telemetry.

### Detections
Screenshots demonstrating security alerts generated by Wazuh.

### Investigations
Screenshots containing detailed event and detection information used during analysis.

### Incidents
Screenshots associated with individual incident investigations.

## Security

Screenshots are reviewed and sanitized before publication.

The repository must not contain:

- Passwords
- API keys
- Authentication tokens
- Private keys
- Secrets
- Sensitive personal information
