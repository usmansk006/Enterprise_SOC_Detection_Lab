# 03 — Threat Hunting

This section documents proactive threat hunting activities performed against endpoint telemetry collected by Wazuh.

## Hunting Process

1. Define a threat hypothesis
2. Identify relevant telemetry
3. Develop search queries
4. Analyze observed activity
5. Investigate suspicious findings
6. Document conclusions

## Objectives

- Identify suspicious authentication activity
- Investigate Windows security events
- Search for anomalous endpoint behavior
- Develop repeatable threat-hunting workflows
- Document findings and supporting evidence
