# DET-008 — CertUtil LOLBin File Decoding

## Overview

This detection identifies the use of `certutil.exe`, a legitimate Windows utility, to decode files.

`CertUtil.exe` is a Microsoft Windows binary that can perform certificate-related operations. However, it can also be abused as a Living Off the Land Binary (LOLBin) to decode encoded files. Attackers may abuse legitimate Windows utilities to reduce the need for additional tools and blend malicious activity with normal system activity.

This detection validates Wazuh's ability to identify CertUtil file decoding activity using Sysmon process creation telemetry.

## Threat Scenario

An attacker may abuse `certutil.exe` to decode an encoded file.

Because `certutil.exe` is a legitimate Windows binary, its execution alone is not necessarily malicious. Detection therefore focuses on the process command line and the use of the `-decode` argument.

Example behavior:

```text
certutil.exe -decode <encoded_file> <output_file>
```

This activity can be associated with the decoding of files during an attack.

---

## Detection Logic

The detection is based on Windows process creation telemetry generated by Sysmon.

Wazuh monitors Sysmon Event ID 1 and identifies CertUtil executions containing the `-decode` argument.

Detection flow:

```text
CertUtil.exe Execution
        ↓
Sysmon Event ID 1
        ↓
Command Line Contains "-decode"
        ↓
Wazuh Rule 92072
        ↓
Certutil decoding a file
```

## MITRE ATT&CK Mapping

### T1140 — Deobfuscate/Decode Files or Information

Adversaries may decode or deobfuscate files or information to access content or prepare payloads for execution.

In this lab, `certutil.exe` was used to decode a harmless Base64-encoded test file.

---

## Test Procedure

The detection was tested in an authorized Windows lab environment.

A harmless Base64-encoded test file was created and decoded using `certutil.exe`.

The test generated a process creation event containing:

```text
certutil.exe -decode
```

Sysmon recorded the process execution as Event ID 1.

Wazuh processed the telemetry and generated an alert using built-in Rule `92072`.

## Investigation Considerations

When investigating CertUtil decoding activity, an analyst should review:

* Process image
* Command line
* Parent process
* Executing user
* Output file location
* Source encoded file
* Process ancestry
* Hashes of created or decoded files
* Subsequent process execution

The use of `certutil.exe` alone should not automatically be considered malicious.

---

## False Positives

Potential legitimate activity may include:

* Administrative scripts
* Software deployment processes
* Troubleshooting activities
* Security testing
* File conversion or decoding performed by authorized users

Analysts should investigate the surrounding process context before determining whether activity is malicious.

---

## Detection Limitations

This detection focuses on CertUtil executions containing the `-decode` argument.

Potential limitations include:

* CertUtil may be used legitimately.
* Other decoding utilities are not covered by this detection.
* Detection depends on Sysmon Event ID 1 telemetry.
* Missing or incomplete command-line logging can reduce detection visibility.

---

## Tuning Considerations

Potential tuning improvements include:

* Monitoring unusual parent-child process relationships.
* Investigating executions from suspicious directories.
* Reviewing decoded output files.
* Correlating CertUtil execution with subsequent process execution.
* Identifying unusual users or execution contexts.

Any exclusions should be based on verified legitimate behavior.
