# DET-007: Suspicious PowerShell Parent-Child Process Execution

## Overview

This detection investigates PowerShell spawning another PowerShell process. Nested PowerShell execution can occur during legitimate administrative activity, automation, or scripting. However, attackers may also use nested PowerShell execution to create multi-stage execution chains and reduce visibility into the original execution context.

This detection demonstrates the complete security monitoring workflow:

**ATTACK → TELEMETRY → DETECT → INVESTIGATE → DOCUMENT**

---

## Detection

The detection identifies a PowerShell process creating a child PowerShell process.

Observed process relationship:

```text
powershell.exe
        ↓
powershell.exe
````

## Detection Logic

The detection identifies the following process relationship:

```text
ParentImage = powershell.exe
Image = powershell.exe
```

Wazuh generated the alert using:

| Field       | Value                                          |
| ----------- | ---------------------------------------------- |
| Rule ID     | 92027                                          |
| Description | Powershell process spawned powershell instance |
| Rule Level  | 4                                              |

---

## Test Procedure

The behavior was generated in an authorized Windows lab environment using:

```powershell
powershell.exe -NoProfile -Command "Write-Output DET007-PARENT-CHILD-TEST"
```

This created a nested PowerShell process.

## Detection Limitations

Nested PowerShell execution is not inherently malicious.

Legitimate use cases include:

* Administrative automation
* Scripts
* Software deployment
* System management tools

Additional context is required to determine whether the activity is malicious.

---

## Conclusion

The test successfully demonstrated the detection of a PowerShell process spawning another PowerShell process.

Sysmon generated the endpoint telemetry, and Wazuh successfully identified the parent-child relationship.

The investigation confirmed the execution chain and collected relevant process context for further analysis.
