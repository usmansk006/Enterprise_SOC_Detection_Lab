

The Wazuh event contained the Script Block field:


The observed value contained:

```text

```

This confirmed that the alert was based on actual PowerShell execution telemetry.

---

# 5. Command Analysis

The command executed was:

```powershell
secedit /export /cfg "$env:TEMP\DET-002-secpol.cfg"
```

The command can be broken down as follows.

## secedit

`secedit` is a Windows command-line utility used to configure and analyze security settings.

It can interact with Windows security policy configuration.

---

## /export

The `/export` option exports security policy configuration.

The activity does not directly modify the security policy.

Instead, it retrieves and exports configuration information.

---

## /cfg

The `/cfg` parameter specifies the configuration file.

In this test, the exported configuration was written to:

```text
%TEMP%\DET-002-secpol.cfg
```

---

# 6. Why This Activity Was Detected

Security policy discovery can be relevant during post-compromise activity.

An attacker may attempt to understand the security configuration of a compromised system.

Possible information of interest could include:

- Password policies
- Account lockout policies
- Security configuration
- Local security settings

Understanding the security configuration of a system may help an attacker make further decisions.

However, the use of `secedit` alone does not indicate malicious activity.

The command must be investigated in context.

This investigation demonstrated the following SOC principles.

A detection alone does not prove malicious activity.

The following must be investigated:


A Level 8 alert requires investigation.


Raw event data is essential during investigations.

- Timestamp

- Process

- Related commands
