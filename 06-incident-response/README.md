# 06 — Incident Response

This section documents the incident response procedures used within the Wazuh SOC homelab.

## Response Lifecycle

1. Preparation
2. Identification
3. Analysis
4. Containment
5. Eradication
6. Recovery
7. Lessons Learned

## Response Activities

- Validate the security alert
- Identify the affected endpoint
- Determine the scope and impact
- Collect relevant evidence
- Identify indicators of compromise
- Contain the activity when appropriate
- Perform remediation
- Validate recovery
- Document lessons learned

## Evidence

Incident response activities are supported by Wazuh alerts, Windows event telemetry, investigation timelines, and other relevant lab evidence.
