# Legacy detections

This directory preserves older Wazuh-aligned or legacy detection material that may still provide educational or historical value. The content is retained for context but is not treated as the primary HTA detection architecture.

## Purpose

- preserve useful historical work,
- avoid data loss from prior project evolution,
- and maintain a clear boundary between legacy content and the modern HTA-focused detection architecture.

## Guidance

Review legacy content before reuse. Some rules may be Wazuh-specific or not directly applicable to the current architecture.
