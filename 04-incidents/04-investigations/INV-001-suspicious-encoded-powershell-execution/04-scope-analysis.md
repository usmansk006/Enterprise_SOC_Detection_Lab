# INV-001 — Scope Analysis

## Scope Analysis Objective

The purpose of scope analysis was to determine whether the observed encoded PowerShell execution was an isolated event or part of broader related activity.

The analysis was performed using available Wazuh telemetry from the monitored endpoint.

---

# 1. Investigation Scope

The scope analysis focused on:

- Additional alerts generated by the same detection rule
- Additional use of the `-EncodedCommand` parameter
- Related PowerShell execution within the selected investigation timeframe

The analysis was limited to the available telemetry collected in the laboratory environment.

---

# 2. Detection Rule Scope

The Wazuh environment was searched using:

```text
rule.id:100105
````

## Result

One matching alert was identified.

This confirms that only one event matched Wazuh detection rule `100105` within the selected search scope.

This does not prove that only one PowerShell process executed on the endpoint.

---

# 3. Encoded Command Scope

The Wazuh environment was searched for:

```text
-EncodedCommand
```

## Result

One relevant result was identified.

The result corresponded to the encoded PowerShell execution under investigation.

No additional encoded PowerShell activity was identified within the selected investigation scope.

---

# 4. PowerShell Activity Review

Relevant PowerShell activity was reviewed within the selected investigation timeframe.

One relevant PowerShell execution associated with the encoded command was identified.

The available telemetry did not identify additional related encoded PowerShell executions.

---

# 5. Scope Assessment

Based on the available Wazuh telemetry:

* One alert matched detection rule `100105`.
* One relevant encoded PowerShell execution was identified.
* No additional related encoded PowerShell executions were identified within the selected investigation scope.

The observed activity appeared isolated within the available telemetry.

---

# 6. Scope Limitations

The scope analysis was limited to:

* Available Wazuh telemetry
* The monitored laboratory endpoint
* The selected investigation timeframe

Therefore, the analysis cannot establish that no similar activity occurred outside the available telemetry or outside the selected investigation scope.

---

# Scope Conclusion

Within the selected investigation timeframe and available Wazuh telemetry, the encoded PowerShell execution appeared to be an isolated event.

No additional related encoded PowerShell executions were identified during the scope analysis.
