# 01 — Lab Environment

This section documents the architecture, deployment, configuration, and validation of the Wazuh SOC homelab.

## Environment

- Wazuh Server
- Windows Endpoint
- VMware virtualization
- Wazuh Agent
- Wazuh Dashboard

## Objectives

- Deploy a functional SOC monitoring environment
- Collect endpoint security telemetry
- Validate agent connectivity
- Monitor Windows security events
- Establish the foundation for detection engineering and threat hunting
